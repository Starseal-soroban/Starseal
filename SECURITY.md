# Security policy

## Status

Starseal is experimental and has not been audited. Don't use it to protect real funds. Deploy to testnet only.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue or pull request for a security problem.

Include:

- What is affected (contract, SDK, CLI) and which version or commit
- Steps to reproduce, or a proof of concept
- The impact you expect

We aim to acknowledge reports within 7 days. This is a small, volunteer-run project, so fixes are best effort; we'll keep you updated and credit you in the release notes unless you'd rather stay anonymous.

## Scope

In scope: the contracts, packages and examples in this repository.

Out of scope: the Soroban host functions, OpenZeppelin's smart-account contracts, OpenBao, and other third-party code. Report those to their own maintainers.
